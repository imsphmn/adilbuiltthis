# Adil Gym App

A private, self contained workout tracking web app prepared for GitHub and Cloudflare Pages.

## Files to upload

Upload every file in this folder to the root of one private GitHub repository. `index.html` must remain at the root.

## Cloudflare Pages settings

- Framework preset: None
- Production branch: main
- Build command: leave blank
- Build output directory: leave blank, or use `/` if the form requires a value

After deployment, connect the custom domain `gym.adilbuiltthis.vip` in the Cloudflare Pages project.

## Important data note

Workout records are stored locally on the device under the website domain. Export a backup before clearing Safari data, replacing the phone, or moving the app to a different domain.
